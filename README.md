# WXalert

**WXalert** is a weather alert application that monitors severe weather sirens and provides state‑based alerts. It pulls data from JSON files containing siren information by state and displays real‑time alerts to users.

## Features

- Parses siren data per state (`data/sirens.bystate.json`, `data/states.json`)
- Simple HTML interface (`index.html`)
- Designed for easy integration with notification systems

## Setup

1. Clone the repository: `git clone https://github.com/Eric-Lautanen/wxalert.git`
2. Ensure SSH key is configured for GitHub if using git operations.
3. Run `index.html` in a browser or integrate with your alert pipeline.
